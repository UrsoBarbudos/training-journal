# Training Journal

Локальное мобильное PWA для ведения тренировки по плану из чата.

## Что умеет

- импортирует обычный текст тренировки из ChatGPT и показывает preview до сохранения;
- различает общую разминку, разминочные и рабочие подходы, RPE и заметки;
- сохраняет скрытую совместимость со старыми JSON v1 и Markdown-планами;
- позволяет быстро менять вес и повторения с цифровой клавиатуры;
- добавляет и удаляет подходы, меняет порядок, заменяет или пропускает упражнения;
- хранит одну универсальную отмену последнего действия;
- запускает ручной таймер отдыха на 1:30, 3:00 или своё время;
- фиксирует боль, дискомфорт и мобильность поясницы после тренировки;
- собирает фактически заполненный текстовый результат для копирования обратно в чат;
- полностью удаляет тренировку из истории или из открытого экрана после подтверждения;
- хранит журнал локально в IndexedDB и защищает доступ локальным PIN-кодом.

## Локальный запуск

Сборка не требуется. Запустите статический сервер из папки проекта:

```bash
python3 -m http.server 8000
```

После этого откройте `http://localhost:8000`.

## Тесты

## Односторонняя синхронизация

Приложение всегда сохраняет тренировку в IndexedDB и только затем отправляет её в отдельный PostgreSQL через HTTPS API. Настройки API открываются кнопкой с шестерёнкой. Локальный PIN не отправляется на сервер и не заменяет Bearer-токен.

Backend находится в `backend/`. Локальная подготовка без изменения `rdfilms_crm`:

```bash
cd backend
uv sync --extra dev
psql postgres -v training_journal_password='ВСТАВЬТЕ_СИЛЬНЫЙ_ПАРОЛЬ' -f create-local-db.sql
cp .env.example .env
uv run alembic upgrade head
uv run uvicorn training_journal_api.main:app --host 127.0.0.1 --port 8080
```

Для интеграционных тестов используйте только отдельную базу с суффиксом `_test`:

```bash
createdb training_journal_api_test
TRAINING_JOURNAL_TEST_DATABASE_URL=postgresql+psycopg://localhost/training_journal_api_test uv run pytest -q
dropdb training_journal_api_test
```

## iPhone

Откройте опубликованную HTTPS-версию в Safari и выберите «Поделиться» → «На экран “Домой”». Таймер хранит время завершения, поэтому после возврата в приложение показывает актуальный остаток или просрочку.

Системное уведомление запрашивается при первом запуске таймера. Точная доставка фонового сигнала зависит от ограничений iOS и режима установленного PWA; её следует проверить на физическом устройстве.
